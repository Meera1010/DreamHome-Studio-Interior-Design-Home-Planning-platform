# DreamHome Studio — SaaS User Manual & Feature Guide

Welcome to **DreamHome Studio**! This guide details how to use all features of the application.

---

## 1. 2D Interactive Room Studio

1. Navigate to **2D Room Studio** from the left sidebar.
2. **Selecting & Moving Items**: Click any furniture item on canvas. Drag to reposition.
3. **Property Inspector**: Use the right sidebar to change item width, depth, rotation angle ($0^\circ-360^\circ$), color, or z-index layer.
4. **Catalog Drawer**: Drag or click items from the catalog drawer to add them to your room layout.
5. **Undo / Redo**: Use the top control bar buttons to step back or forward through design changes.
6. **Exporting**: Click **Export PNG** for high-res images, **Export JSON** for project backups, or **Save Layout** to persist changes to the database.

---

## 2. Projects & Floor Planning

* Create multi-room projects.
* Assign clients and set budget limits.
* View version history snapshots to restore previous design iterations.

---

## 3. Cost Calculator & Budgeting

* Dynamic cost breakdown based on room furniture, wall paint surface area, flooring material per $m^2$, installation labor, sales tax, and designer margins.
* Export itemized cost reports to CSV.

---

## 4. Admin Panel & Security Audit Logs

* Admins can view all registered accounts, change user roles (`Designer`, `Client`, `Admin`), toggle active status, and inspect security audit logs.
